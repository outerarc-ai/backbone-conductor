# Security policy

Backbone Conductor stores coordination history in Git and can expose authenticated HTTP and MCP endpoints. Operators are responsible for protecting repository access, bearer tokens, TLS private keys, and any provider credentials.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on the [repository Security page](https://github.com/outerarc-ai/backbone-conductor/security) when available. Do not include exploitable details, credentials, or private data in a public issue. If private reporting is unavailable, contact the repository maintainers through their GitHub profiles to arrange a private channel.

Include the affected version, a concise reproduction, impact, and any suggested mitigation. Maintainers will acknowledge receipt and coordinate disclosure before publishing a fix.

Supported releases are listed on the [GitHub Releases page](https://github.com/outerarc-ai/backbone-conductor/releases). Users should upgrade to the latest available release before reporting a resolved issue.
