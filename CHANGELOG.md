# Changelog

## 0.1.0

First open-source release under OuterArc AI.

- Coordinate intentions, decisions, task assignments, Git artifacts, and approvals in a Git-backed ledger.
- Inspect decision lineage and intention lifecycles through read-only browser maps.
- Use role-scoped CLI, HTTP, and MCP interfaces, including the repository's Codex plugin.
- Verify submitted Git commits, target-branch integration, and approval anchors.
- Audit ledger snapshots and reachable history; use optional DeepSeek Harness advice without delegating approval authority.

For supported workflows and limitations, see the [documentation](docs/README.md).
